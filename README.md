## 🎦 What's Included

### 🧠 **Crux Plugin** - Memory That Never Forgets
**Solves Context Compaction with a Causal Graph**

Never again lose the "why" behind your architectural decisions. Crux stores decisions as causal triples (CONSTRAINT → RATIONALE → DECISION) that survive context compaction.

**Perfect for**: Long-term projects, team collaborations, complex architectural decisions.

### 🛡️ **Security Skills Collection** - Production-Ready Security
**Enterprise-grade security skills for safe AI interactions**

- **prompt-guard**: Unbreakable protection against injection and jailbreaks
- **next-loading-skeleton**: Beautiful loading states for Next.js applications

**Perfect for**: Production environments, security-conscious teams, public applications.

## 🚀 Quick Start

### 1. Add the Marketplace
```bash
/plugin marketplace add akashp1712/claude-marketplace
```

### 2. Install What You Need

#### Install Crux Plugin
```bash
/plugin install crux@akashp1712
```

#### Install Individual Skills
```bash
# Security protection
npx skills add akashp1712/skills --skill prompt-guard

# Better UX for Next.js
npx skills add akashp1712/skills --skill next-loading-skeleton

# Reclaim disk from stale dev caches
npx skills add akashp1712/skills --skill workspace-disk-cleanup
```

### 3. Start Creating!
That's it! Your tools are now ready to enhance your Claude Code experience.
